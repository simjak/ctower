Brief

manibo drove the shadow instance end to end and hit the wall first: a project seat has no way to obtain its own credential, so every write still borrows the ctower commander's authority. Until a seat can hold a scoped, revocable credential of its own, no other project can file against its own board, and the 115-item manibo ledger cannot start moving.

This issues per-(project, seat) credentials with named scopes, revocable by the operator, and refuses every issuance path that does not name its authority. Cross-project mutation refuses by name — that is the isolation D29 sold to the operator, and it is the clause that has to be proven, not asserted.
