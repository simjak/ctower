# Support

ctower is pre-alpha and has no supported runtime, hosted service, or compatibility guarantee yet.

- Read the [documentation](https://simjak.github.io/ctower/) and
  [project status](https://simjak.github.io/ctower/project-status/) first.
- Use [GitHub Discussions](https://github.com/simjak/ctower/discussions) for public questions and design
  conversations when Discussions are enabled.
- Use the repository issue forms for reproducible defects, focused feature proposals, and documentation
  problems.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Never post security details publicly.

Community support is best effort until the project publishes a supported release. Please provide synthetic,
minimal reproductions and never include credentials, personal data, customer data, or private infrastructure
details.
