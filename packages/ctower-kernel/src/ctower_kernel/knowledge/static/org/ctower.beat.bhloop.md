# Delivery and access sweep

Sweep the delivery lane end to end: process the reports waiting in the director inbox, capture and
push the pane of any lane that has been silent for two or more consecutive windows, and confirm
that every operator-facing link actually serves. A link that does not serve is a P1 raised by name
against the owning seat. Track the delivery counters through the owning seat and report movement
only; a window with no movement closes with the single no-movement line and its evidence artifact.
