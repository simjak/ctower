# Operator morning digest

Compose one compact operator update in three named sections. DECISIONS WAITING lists every open
operator-gated item as a self-contained brief: what it is in plain words, where it came from, the
choices stated as outcomes, the recommendation, and the safe default; verify each item is still
open before listing it. YESTERDAY'S DECISIONS says what was executed against them. CLOSED SINCE
LAST DIGEST names each closure with its proof word. Identities go in parentheses, sentences stay
plain, and nothing is invented — every line is verified against the recorded source first. When
nothing is waiting and nothing closed, the digest is the single line saying so.
